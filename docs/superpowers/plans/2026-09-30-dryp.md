# dryp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build dryp — a `dryp` CLI plus a native macOS menu-bar agent that keeps the Mac awake in two independent modes (`caf` = caffeinate-style assertions, `nosleep` = `pmset disablesleep` via a narrow sudoers rule), replacing the user's zsh aliases.

**Architecture:** One SwiftPM package. `DrypCore` holds all logic (models, locked state store, policy, scheduling, a `Reconciler` written against driver protocols) and is unit-tested with fakes. The CLI (`DrypCLI` + `dryp`) only writes requests to `~/.config/dryp/state.json` and waits for the agent's acknowledgement in `~/.local/share/dryp/applied.json`. The agent (`DrypApp`, launched by launchd as `Dryp.app`) is the only process that creates power assertions or runs `pmset`; it reconciles on every file change, timer, battery change, wake and clock change.

**Tech Stack:** Swift 6 toolchain in Swift 5 language mode, SwiftPM, swift-argument-parser ≥ 1.5, Swift Testing (`import Testing`), AppKit (`NSStatusItem`/`NSMenu`), IOKit (`IOPMAssertion`, `IOPowerSources`), UserNotifications, launchd, bash.

**Spec:** `docs/superpowers/specs/2026-09-30-dryp-design.md` — read it before starting any task; this plan argues from it.

## Global Constraints

- Platform: macOS 13+ (`platforms: [.macOS(.v13)]`, `LSMinimumSystemVersion` 13.0).
- Package: `swift-tools-version: 6.0`, `swiftLanguageModes: [.v5]`; only external dependency is `https://github.com/apple/swift-argument-parser` from `1.5.0`.
- Names: command `dryp`; app `Dryp.app` (executable `Dryp`); bundle ID and launchd label `io.github.00mkp.dryp`.
- Paths: app in `$APP_DIR` (default `~/Applications`); CLI `~/.local/bin/dryp`; requests `~/.config/dryp/state.json` (+ `state.lock`, `state.json.bad`); agent files `~/.local/share/dryp/` (`applied.json`, `manifest`, `start`); log `~/Library/Logs/dryp.log`; agent plist `~/Library/LaunchAgents/io.github.00mkp.dryp.plist`; sudoers `/etc/sudoers.d/dryp`.
- Sudoers rule, exactly: `<user> ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 0, /usr/bin/pmset -a disablesleep 1`.
- Every sudo call from dryp is `sudo -k -n …` (never prompts; ignores cached credentials).
- caf assertions: `PreventUserIdleDisplaySleep`, `PreventUserIdleSystemSleep`, `PreventDiskIdle`, `PreventSystemSleep`, plus `IOPMAssertionDeclareUserActivity` at start.
- Durations: bare number = whole minutes ≥ 1; `-h`/`--hours` = hours, decimals allowed, ≥ 1 minute after rounding; max 8760 h. Help is `--help` only.
- Exit codes: 0 success, 1 failure, 2 usage.
- Warning lead 5 min, only for sessions ≥ 10 min; Extend = +1 hr; low battery = on battery and ≤ 10 %.
- Restore retry backoff: 5 s, 30 s, 2 min, then every 5 min.
- Defaults: `showTimeCaf` false, `showTimeNosleep` false, `openAtLogin` true.
- Dates in JSON are ISO-8601 at whole seconds; always build sessions from `Date().wholeSeconds`.
- Tests: Swift Testing; run with `scripts/test.sh` (handles Command-Line-Tools-only Macs, which this machine is).
- Git: commit after every task on a feature branch; never commit `.build/`.

## Review Focus

1. **Cached sudo credentials hiding a missing rule** — if the user ran `sudo` recently, a plain `sudo -n` succeeds without the rule, and the later unattended restore fails. Expect dryp to treat nosleep as "not set up" unless the NOPASSWD rule itself works. Pinned in Task 7 (`PmsetCommand` always includes `-k -n`).
2. **Odd durations** — `0`, `1.5` minutes, `inf`, `nan`, `99999999`, `0.001 -h`. Expect a one-line explanation and exit 2, never a session. Pinned in Task 3 (parser) and Task 11 (CLI exit codes).
3. **`state.json` deleted or corrupted while `applied.rev` is high** — a naive counter restarts at 1 and the CLI would see a stale acknowledgement as success. Expect `rev` to keep rising. Pinned in Task 4.
4. **CLI and menu writing at the same moment** — the agent must not clear a session that was replaced between its read and its write. Expect the new session to survive. Pinned in Task 4 (`StateStore.clear` only clears unchanged sessions).
5. **The Mac sleeping or the clock jumping past a deadline** — expect exactly one end notice at wake and no warning for an already-ended session. Pinned in Task 8.

`Sources/DrypCore/Models.swift`:
```swift
import Foundation

public enum Mode: String, Codable, CaseIterable, Sendable {
    case caf, nosleep

    /// How the menu and notifications name the mode.
    public var title: String { self == .caf ? "Caffeinate" : "Nosleep" }
}

/// One running mode. `until == nil` means no limit.
public struct Session: Codable, Equatable, Sendable {
    public var started: Date
    public var until: Date?

    public init(started: Date, until: Date?) {
        self.started = started
        self.until = until
    }

    public var isUnlimited: Bool { until == nil }
}

public struct Prefs: Codable, Equatable, Sendable {
    public var showTimeCaf = false
    public var showTimeNosleep = false
    public var openAtLogin = true

    public init() {}

    public func showsTime(_ mode: Mode) -> Bool { mode == .caf ? showTimeCaf : showTimeNosleep }

    public mutating func setShowsTime(_ mode: Mode, _ on: Bool) {
        if mode == .caf { showTimeCaf = on } else { showTimeNosleep = on }
    }

    enum CodingKeys: String, CodingKey { case showTimeCaf, showTimeNosleep, openAtLogin }

    // Every key is optional on disk so older or hand-edited files still load.
    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        showTimeCaf = try c.decodeIfPresent(Bool.self, forKey: .showTimeCaf) ?? false
        showTimeNosleep = try c.decodeIfPresent(Bool.self, forKey: .showTimeNosleep) ?? false
        openAtLogin = try c.decodeIfPresent(Bool.self, forKey: .openAtLogin) ?? true
    }
}

/// The requests file, `~/.config/dryp/state.json`. Written by the CLI and the menu; read by the agent.
public struct DrypState: Codable, Equatable, Sendable {
    public static let currentVersion = 1

    public var version = DrypState.currentVersion
    public var rev = 0
    public var caf: Session?
    public var nosleep: Session?
    /// One-shot request: set disablesleep 0 even if dryp didn't set it. The agent clears it.
    public var restoreSleep = false
    public var prefs = Prefs()

    public init() {}

    public subscript(mode: Mode) -> Session? {
        get { mode == .caf ? caf : nosleep }
        set { if mode == .caf { caf = newValue } else { nosleep = newValue } }
    }

    public var anyActive: Bool { caf != nil || nosleep != nil }

    enum CodingKeys: String, CodingKey { case version, rev, caf, nosleep, restoreSleep, prefs }

    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        version = try c.decodeIfPresent(Int.self, forKey: .version) ?? DrypState.currentVersion
        guard version == DrypState.currentVersion else {
            throw DecodingError.dataCorruptedError(
                forKey: .version, in: c, debugDescription: "unsupported state version \(version)")
        }
        rev = try c.decodeIfPresent(Int.self, forKey: .rev) ?? 0
        caf = try c.decodeIfPresent(Session.self, forKey: .caf)
        nosleep = try c.decodeIfPresent(Session.self, forKey: .nosleep)
        restoreSleep = try c.decodeIfPresent(Bool.self, forKey: .restoreSleep) ?? false
        prefs = try c.decodeIfPresent(Prefs.self, forKey: .prefs) ?? Prefs()
    }

    // Explicit so that an off mode is written as `null` rather than omitted.
    public func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: CodingKeys.self)
        try c.encode(version, forKey: .version)
        try c.encode(rev, forKey: .rev)
        try c.encode(caf, forKey: .caf)
        try c.encode(nosleep, forKey: .nosleep)
        try c.encode(restoreSleep, forKey: .restoreSleep)
        try c.encode(prefs, forKey: .prefs)
    }
}

public struct Rejection: Codable, Equatable, Sendable {
    public var mode: Mode
    public var reason: String
    /// The state revision the agent was looking at when it refused.
    public var rev: Int

    public init(mode: Mode, reason: String, rev: Int) {
        self.mode = mode
        self.reason = reason
        self.rev = rev
    }
}

/// The agent's record of what it actually did, `~/.local/share/dryp/applied.json`. Agent-only writer.
public struct Applied: Codable, Equatable, Sendable {
    public var rev = 0
    public var cafHeld = false
    /// True when dryp itself set disablesleep 1 — what makes a disabled sleep "owned" rather than foreign.
    public var nosleepSet = false
    public var rejected: Rejection?
    public var restoreFailed = false

    public init() {}

    enum CodingKeys: String, CodingKey { case rev, cafHeld, nosleepSet, rejected, restoreFailed }

    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        rev = try c.decodeIfPresent(Int.self, forKey: .rev) ?? 0
        cafHeld = try c.decodeIfPresent(Bool.self, forKey: .cafHeld) ?? false
        nosleepSet = try c.decodeIfPresent(Bool.self, forKey: .nosleepSet) ?? false
        rejected = try c.decodeIfPresent(Rejection.self, forKey: .rejected)
        restoreFailed = try c.decodeIfPresent(Bool.self, forKey: .restoreFailed) ?? false
    }
}

public enum DrypJSON {
    public static let encoder: JSONEncoder = {
        let e = JSONEncoder()
        e.dateEncodingStrategy = .iso8601
        e.outputFormatting = [.prettyPrinted, .sortedKeys]
        return e
    }()

    public static let decoder: JSONDecoder = {
        let d = JSONDecoder()
        d.dateDecodingStrategy = .iso8601
        return d
    }()
}

extension Date {
    /// ISO-8601 on disk has no fractional seconds; build sessions from this so they compare equal after a round trip.
    public var wholeSeconds: Date { Date(timeIntervalSince1970: timeIntervalSince1970.rounded(.down)) }
}
```

```swift
import Foundation

public enum DurationError: Error, Equatable, CustomStringConvertible {
    case notANumber(String)
    case notWholeMinutes(String)
    case tooShort
    case tooLong

    public var description: String {
        switch self {
        case .notANumber(let s): return "'\(s)' isn't a number"
        case .notWholeMinutes(let s): return "minutes must be a whole number ('\(s)'); use -h for fractional hours"
        case .tooShort: return "duration must be at least 1 minute"
        case .tooLong: return "duration can be at most 8760 hours (one year)"
        }
    }
}

public enum DurationParser {
    public static let maxSeconds: TimeInterval = 8760 * 3600

    /// Bare numbers are whole minutes; with `hours`, decimals are allowed and rounded to the nearest minute.
    /// Returns seconds.
    public static func parse(_ text: String, hours: Bool) throws -> TimeInterval {
        let t = text.trimmingCharacters(in: .whitespaces)
        if hours {
            guard let h = Double(t), h.isFinite else { throw DurationError.notANumber(text) }
            return try checked(minutes: (h * 60).rounded())
        }
        if let m = Int(t) { return try checked(minutes: Double(m)) }
        if let d = Double(t), d.isFinite { throw DurationError.notWholeMinutes(text) }
        throw DurationError.notANumber(text)
    }

    private static func checked(minutes: Double) throws -> TimeInterval {
        guard minutes >= 1 else { throw DurationError.tooShort }
        guard minutes * 60 <= maxSeconds else { throw DurationError.tooLong }
        return minutes * 60
    }
}
```

```swift
import Foundation

public enum StoreError: Error, CustomStringConvertible {
    case lockFailed(String)
    public var description: String {
        switch self { case .lockFailed(let why): return "couldn't lock the state file: \(why)" }
    }
}

/// The requests file. Every write is a read-modify-write under an exclusive flock, written atomically.
public struct StateStore: Sendable {
    public enum ReadResult: Equatable { case ok(DrypState), missing, corrupt }

    public let paths: Paths

    public init(paths: Paths) { self.paths = paths }

    public func read() -> ReadResult {
        guard let data = try? Data(contentsOf: paths.stateFile) else { return .missing }
        guard let state = try? DrypJSON.decoder.decode(DrypState.self, from: data) else { return .corrupt }
        return .ok(state)
    }

    /// The current requests, or defaults when the file is missing or unreadable.
    public func current() -> DrypState {
        if case .ok(let s) = read() { return s }
        return DrypState()
    }

    @discardableResult
    public func update(_ body: (inout DrypState) throws -> Void) throws -> DrypState {
        try withLock {
            var state: DrypState
            switch read() {
            case .ok(let s): state = s
            case .missing: state = DrypState()
            case .corrupt: try quarantineLocked(); state = DrypState()
            }
            let before = state
            try body(&state)
            guard state != before else { return state }
            // Wall-clock milliseconds keep rev rising even if the file is deleted and recreated, so a stale
            // applied.rev can never look like an acknowledgement of a fresh request.
            state.rev = max(before.rev + 1, Int((Date().timeIntervalSince1970 * 1000).rounded(.down)))
            try DrypJSON.encoder.encode(state).write(to: paths.stateFile, options: .atomic)
            return state
        }
    }

    /// Clears each mode only if it still holds exactly the given session, so a request written between the
    /// agent's read and this write survives.
    @discardableResult
    public func clear(_ sessions: [Mode: Session]) throws -> DrypState {
        try update { s in
            for (mode, old) in sessions where s[mode] == old { s[mode] = nil }
        }
    }

    /// Moves an unreadable state.json aside to state.json.bad. Returns whether it did.
    public func quarantineCorrupt() throws -> Bool {
        try withLock {
            guard read() == .corrupt else { return false }
            try quarantineLocked()
            return true
        }
    }

    private func quarantineLocked() throws {
        let fm = FileManager.default
        try? fm.removeItem(at: paths.badStateFile)
        try fm.moveItem(at: paths.stateFile, to: paths.badStateFile)
    }

    private func withLock<T>(_ body: () throws -> T) throws -> T {
        try FileManager.default.createDirectory(at: paths.configDir, withIntermediateDirectories: true)
        let fd = open(paths.lockFile.path, O_CREAT | O_RDWR, 0o644)
        guard fd >= 0 else { throw StoreError.lockFailed(String(cString: strerror(errno))) }
        defer { close(fd) }
        guard flock(fd, LOCK_EX) == 0 else { throw StoreError.lockFailed(String(cString: strerror(errno))) }
        defer { flock(fd, LOCK_UN) }
        return try body()
    }
}
```

```swift
import Foundation

/// The agent's record of what it did. Only the agent writes it, so no lock is needed.
public struct AppliedStore: Sendable {
    public let paths: Paths

    public init(paths: Paths) { self.paths = paths }

    public func read() -> Applied {
        guard let data = try? Data(contentsOf: paths.appliedFile),
              let applied = try? DrypJSON.decoder.decode(Applied.self, from: data) else { return Applied() }
        return applied
    }

    public func write(_ applied: Applied) throws {
        try FileManager.default.createDirectory(at: paths.dataDir, withIntermediateDirectories: true)
        try DrypJSON.encoder.encode(applied).write(to: paths.appliedFile, options: .atomic)
    }
}

/// "Stay in the menu bar this launch": written by `dryp app start`, the Finder handoff and install.sh;
/// consumed by the agent's login check.
public enum StartMarker {
    public static func touch(_ paths: Paths) {
        try? FileManager.default.createDirectory(at: paths.dataDir, withIntermediateDirectories: true)
        FileManager.default.createFile(atPath: paths.startMarker.path, contents: Data())
    }

    public static func consume(_ paths: Paths) -> Bool {
        (try? FileManager.default.removeItem(at: paths.startMarker)) != nil
    }
}

/// `~/.local/share/dryp/manifest`, written by install.sh: key=value lines.
public struct Manifest: Equatable, Sendable {
    public var version: String
    public var source: String
    public var appDir: String
    public var nosleep: Bool

    public init(version: String, source: String, appDir: String, nosleep: Bool) {
        self.version = version
        self.source = source
        self.appDir = appDir
        self.nosleep = nosleep
    }

    public static func parse(_ text: String) -> Manifest? {
        var values: [String: String] = [:]
        for line in text.split(separator: "\n") {
            guard let eq = line.firstIndex(of: "=") else { continue }
            values[String(line[..<eq])] = String(line[line.index(after: eq)...])
        }
        guard let version = values["version"], let source = values["source"],
              let appDir = values["app_dir"], let nosleep = values["nosleep"] else { return nil }
        return Manifest(version: version, source: source, appDir: appDir, nosleep: nosleep == "yes")
    }

    public static func read(_ paths: Paths) -> Manifest? {
        guard let text = try? String(contentsOf: paths.manifestFile, encoding: .utf8) else { return nil }
        return parse(text)
    }
}
```

```swift
    }

    public static func decide(_ o: Observation) -> Decision {
        var d = Decision(holdCaf: false, disableSleep: false, clear: [:], endings: [], rejection: nil)

        for mode in Mode.allCases {
            guard let s = o.state[mode], let until = s.until, until <= o.now else { continue }
            d.clear[mode] = s
            d.endings.append(Ending(mode: mode, reason: until < o.bootTime ? .expiredWhileOff : .expired))
        }

        if let s = o.state.nosleep, d.clear[.nosleep] == nil {
            // "Running" means dryp already set disablesleep for it; anything else is a fresh request.
            let running = o.applied.nosleepSet
            if !running && !o.nosleepAvailable {
                d.clear[.nosleep] = s
                d.rejection = Rejection(mode: .nosleep, reason: notSetUpReason, rev: o.state.rev)
            } else if o.power.isLow {
                let percent = o.power.percent ?? 0
                d.clear[.nosleep] = s
                if running {
                    d.endings.append(Ending(mode: .nosleep, reason: .lowBattery(percent)))
                } else {
                    d.rejection = Rejection(mode: .nosleep, reason: lowBatteryReason(percent), rev: o.state.rev)
                }
            }
        }

        d.holdCaf = o.state.caf != nil && d.clear[.caf] == nil
        d.disableSleep = o.state.nosleep != nil && d.clear[.nosleep] == nil
        return d
    }
}
```

```swift
import Foundation

/// A warning is sent once per (mode, deadline); extending changes the deadline, so it can warn again.
public struct WarningKey: Hashable, Sendable {
    public var mode: Mode
    public var until: Date

    public init(mode: Mode, until: Date) {
        self.mode = mode
        self.until = until
    }
}

public enum Schedule {
    public static let warningLead: TimeInterval = 5 * 60
    public static let minimumWarnedLength: TimeInterval = 10 * 60
    public static let restoreBackoff: [TimeInterval] = [5, 30, 120, 300]

    static func warningTime(_ s: Session) -> Date? {
        guard let until = s.until, until.timeIntervalSince(s.started) >= minimumWarnedLength else { return nil }
        return until.addingTimeInterval(-warningLead)
    }

    public static func dueWarnings(_ state: DrypState, now: Date, warned: Set<WarningKey>) -> [Mode] {
        Mode.allCases.filter { mode in
            guard let s = state[mode], let until = s.until, let w = warningTime(s) else { return false }
            return now >= w && now < until && !warned.contains(WarningKey(mode: mode, until: until))
        }
    }

    /// When the agent next needs to look: the earliest pending warning or deadline.
    public static func nextWake(_ state: DrypState, now: Date, warned: Set<WarningKey>) -> Date? {
        var candidates: [Date] = []
        for mode in Mode.allCases {
            guard let s = state[mode], let until = s.until else { continue }
            candidates.append(until)
            if let w = warningTime(s), w > now, !warned.contains(WarningKey(mode: mode, until: until)) {
                candidates.append(w)
            }
        }
        return candidates.min()
    }

    public static func retryDelay(afterFailures failures: Int) -> TimeInterval {
        restoreBackoff[min(max(failures, 1), restoreBackoff.count) - 1]
    }
}

public enum LoginCheck {
    /// At launch: leave quietly when Open at Login is off and nothing needs watching.
    public static func shouldExit(state: DrypState, applied: Applied, foreign: Bool, startRequested: Bool) -> Bool {
        !startRequested && !state.prefs.openAtLogin && !state.anyActive
            && !foreign && !applied.restoreFailed && !applied.nosleepSet
    }
}
```

```swift
import Foundation

public enum Format {
    /// Minutes, rounded up so a session never shows "0m" while it still runs: "42m", "1h", "3h12m".
    public static func remaining(_ seconds: TimeInterval) -> String {
        let minutes = max(0, Int((seconds / 60).rounded(.up)))
        if minutes < 60 { return "\(minutes)m" }
        let h = minutes / 60, m = minutes % 60
        return m == 0 ? "\(h)h" : "\(h)h\(m)m"
    }

    public static func clock(_ date: Date, timeZone: TimeZone = .current) -> String {
        let f = DateFormatter()
        f.locale = Locale(identifier: "en_US_POSIX")
        f.timeZone = timeZone
        f.dateFormat = "HH:mm"
        return f.string(from: date)
    }

    /// The right-hand side of a status row: "off", "on · no limit", "on · 42m left (until 16:52)".
    public static func status(_ session: Session?, now: Date, timeZone: TimeZone = .current) -> String {
        guard let session else { return "off" }
        guard let until = session.until else { return "on · no limit" }
        return "on · \(remaining(until.timeIntervalSince(now))) left (until \(clock(until, timeZone: timeZone)))"
    }

    /// The CLI's confirmation line.
    public static func started(_ mode: Mode, _ session: Session, timeZone: TimeZone = .current) -> String {
        guard let until = session.until else { return "\(mode.rawValue) on, no limit" }
        let length = remaining(until.timeIntervalSince(session.started))
        return "\(mode.rawValue) on for \(length) (until \(clock(until, timeZone: timeZone)))"
    }
}
```

```swift
import Foundation

/// The agent's brain. Every input — file change, timer, battery, wake, clock change, menu action — calls
/// `reconcile()`, which reads the requests, decides, makes the drivers match, and records what it did.
public final class Reconciler {
    private let store: StateStore
    private let appliedStore: AppliedStore
    private let caf: PowerAssertions
    private let sleep: SleepSetting
    private let power: PowerSource
    private let notifier: Notifier
    private let now: () -> Date
    private let bootTime: Date
    private let log: (String) -> Void

    public private(set) var state = DrypState()
    public private(set) var applied: Applied
    public private(set) var foreign = false
    public private(set) var nosleepAvailable: Bool

    private var warned = Set<WarningKey>()
    private var foreignNotified = false
    private var restoreFailures = 0
    private var nextRetry: Date?

    public init(store: StateStore, appliedStore: AppliedStore, caf: PowerAssertions, sleep: SleepSetting,
                power: PowerSource, notifier: Notifier, now: @escaping () -> Date, bootTime: Date,
                log: @escaping (String) -> Void) {
        self.store = store
        self.appliedStore = appliedStore
        self.caf = caf
        self.sleep = sleep
        self.power = power
        self.notifier = notifier
        self.now = now
        self.bootTime = bootTime
        self.log = log
        applied = appliedStore.read()
        nosleepAvailable = sleep.isAvailable()
    }

    public func refreshAvailability() { nosleepAvailable = sleep.isAvailable() }

    /// Returns when the agent next needs to look (a warning, a deadline, or a restore retry), or nil.
    @discardableResult
    public func reconcile() -> Date? {
        let t = now()
        if store.read() == .corrupt, (try? store.quarantineCorrupt()) == true {
            log("state.json was unreadable; moved it to state.json.bad")
        }
        var current = store.current()
        if current.nosleep != nil && !applied.nosleepSet { nosleepAvailable = sleep.isAvailable() }

        let decision = Policy.decide(Observation(now: t, bootTime: bootTime, state: current, applied: applied,
                                                 power: power.current(), nosleepAvailable: nosleepAvailable))
        if let r = decision.rejection { reject(r) }
        if !decision.clear.isEmpty { current = clear(decision.clear, fallback: current) }

        if decision.holdCaf && !caf.isHeld {
            do {
                try caf.hold()
                log("caf: assertions held")
            } catch {
                reject(Rejection(mode: .caf, reason: "couldn't create the power assertions (\(error))", rev: current.rev))
                if let s = current.caf { current = clear([.caf: s], fallback: current) }
            }
        } else if !decision.holdCaf && caf.isHeld {
            caf.release()
            log("caf: assertions released")
        }

        if decision.disableSleep {
            if !disableSleep(rev: current.rev), let s = current.nosleep { current = clear([.nosleep: s], fallback: current) }
        } else {
            restoreSleepIfOwned(at: t)
        }

        current = handleRestoreRequest(current, disabling: decision.disableSleep && current.nosleep != nil)

        let live = sleep.read()
        foreign = live == true && !applied.nosleepSet
        if foreign && !foreignNotified {
            notifier.post(.foreignSleepDisabled)
            log("sleep is disabled outside dryp")
        }
        foreignNotified = foreign

        for e in decision.endings {
            notifier.post(.ended(e))
            log("\(e.mode.rawValue): ended (\(e.reason))")
        }
        for mode in Schedule.dueWarnings(current, now: t, warned: warned) {
            if let until = current[mode]?.until { warned.insert(WarningKey(mode: mode, until: until)) }
            notifier.post(.warning(mode))
        }

        state = current
        applied.rev = current.rev
        applied.cafHeld = caf.isHeld
        persistApplied()

        let wake = Schedule.nextWake(current, now: t, warned: warned)
        let retry = applied.restoreFailed ? nextRetry : nil
        return [wake, retry].compactMap { $0 }.min()
    }

    /// Adds `seconds` to a timed session's deadline. No-op for unlimited or stopped modes.
    public func extend(_ mode: Mode, by seconds: TimeInterval) {
        do {
            try store.update { s in
                guard var session = s[mode], let until = session.until else { return }
                session.until = until.addingTimeInterval(seconds)
                s[mode] = session
            }
            log("\(mode.rawValue): extended by \(Int(seconds / 60))m")
        } catch {
            log("extend failed: \(error)")
        }
    }

    /// Completed in Task 9.
    @discardableResult
    public func shutdown() -> Bool { true }

    // MARK: - Steps

    private func reject(_ r: Rejection) {
        applied.rejected = r
        log("rejected \(r.mode.rawValue): \(r.reason)")
    }

    private func clear(_ sessions: [Mode: Session], fallback: DrypState) -> DrypState {
        do {
            return try store.clear(sessions)
        } catch {
            log("couldn't write state.json: \(error)")
            return fallback
        }
    }

    /// Makes SleepDisabled 1 and owned. False (with a rejection) if pmset didn't take.
    private func disableSleep(rev: Int) -> Bool {
        if sleep.read() == true {
            if !applied.nosleepSet { log("nosleep: sleep was already disabled; dryp now owns it") }
            applied.nosleepSet = true
            return true
        }
        sleep.set(disabled: true)
        guard sleep.read() == true else {
            reject(Rejection(mode: .nosleep, reason: "pmset didn't disable sleep (see ~/Library/Logs/dryp.log)", rev: rev))
            return false
        }
        applied.nosleepSet = true
        log("nosleep: sleep disabled")
        return true
    }

    /// Completed in Task 9 (retries and failure reporting). Happy path: restore and disown.
    private func restoreSleepIfOwned(at t: Date) {
        guard applied.nosleepSet else { return }
        sleep.set(disabled: false)
        if sleep.read() == false {
            applied.nosleepSet = false
            log("nosleep: sleep restored")
        }
    }

    /// Completed in Task 9.
    private func handleRestoreRequest(_ current: DrypState, disabling: Bool) -> DrypState { current }

    private func persistApplied() {
        do { try appliedStore.write(applied) } catch { log("couldn't write applied.json: \(error)") }
    }
}
```

```swift
import Foundation

public enum Shell {
    public struct Result: Equatable, Sendable {
        public var status: Int32
        public var output: String

        public init(status: Int32, output: String) {
            self.status = status
            self.output = output
        }
    }

    /// Runs a tool with stdout+stderr captured and no stdin. 127 = couldn't launch, 124 = timed out.
    @discardableResult
    public static func run(_ path: String, _ args: [String], timeout: TimeInterval = 10) -> Result {
        let process = Process()
        process.executableURL = URL(fileURLWithPath: path)
        process.arguments = args
        let pipe = Pipe()
        process.standardOutput = pipe
        process.standardError = pipe
        process.standardInput = FileHandle.nullDevice
        let exited = DispatchSemaphore(value: 0)
        process.terminationHandler = { _ in exited.signal() }
        do { try process.run() } catch { return Result(status: 127, output: error.localizedDescription) }

        var data = Data()
        let readDone = DispatchSemaphore(value: 0)
        DispatchQueue.global().async {
            data = pipe.fileHandleForReading.readDataToEndOfFile()
            readDone.signal()
        }
        if exited.wait(timeout: .now() + timeout) == .timedOut {
            process.terminate()
            return Result(status: 124, output: "timed out after \(timeout)s")
        }
        readDone.wait()
        return Result(status: process.terminationStatus, output: String(decoding: data, as: UTF8.self))
    }

    /// Runs a tool attached to this terminal (sudo prompts, git, install.sh). Returns its exit status.
    public static func interactive(_ path: String, _ args: [String], environment: [String: String] = [:]) -> Int32 {
        let process = Process()
        process.executableURL = URL(fileURLWithPath: path)
        process.arguments = args
        if !environment.isEmpty {
            process.environment = ProcessInfo.processInfo.environment.merging(environment) { $1 }
        }
        do { try process.run() } catch { return 127 }
        process.waitUntilExit()
        return process.terminationStatus
    }

    public static func liveSleepDisabled() -> Bool? {
        Pmset.sleepDisabled(fromLive: run(PmsetCommand.pmset, PmsetCommand.readLive).output)
    }
```

```swift
    public static var domain: String { "gui/\(getuid())" }
    public static var target: String { "\(domain)/\(Paths.label)" }

    public static func pid(fromPrint output: String) -> Int? {
        for line in output.split(separator: "\n") {
            let trimmed = line.trimmingCharacters(in: .whitespaces)
            if trimmed.hasPrefix("pid = ") { return Int(trimmed.dropFirst("pid = ".count)) }
        }
        return nil
    }
}

/// How the CLI (and the Finder handoff) reach the launchd-managed agent. Injectable for tests.
public struct AgentControl {
    /// The agent's pid, or nil if it isn't running.
    public var pid: () -> Int?
    /// Loads (bootstrap) or starts (kickstart) the agent. True if launchctl succeeded.
    public var start: () -> Bool
    /// Sends SIGTERM (the agent runs its shutdown routine) and waits up to 10 s for it to exit.
    public var stop: () -> Bool
    /// Called after every state write. The live agent notices through its file watcher, so this is a no-op;
    /// tests reconcile synchronously here.
    public var nudge: () -> Void

    public init(pid: @escaping () -> Int?, start: @escaping () -> Bool, stop: @escaping () -> Bool,
                nudge: @escaping () -> Void = {}) {
        self.pid = pid
        self.start = start
        self.stop = stop
        self.nudge = nudge
    }

    public static func live(paths: Paths) -> AgentControl {
        let launchctl = "/bin/launchctl"
        func printed() -> Shell.Result { Shell.run(launchctl, ["print", Launchctl.target]) }
        func pid() -> Int? {
            let r = printed()
            return r.status == 0 ? Launchctl.pid(fromPrint: r.output) : nil
        }
        return AgentControl(
            pid: pid,
            start: {
                if printed().status != 0 {
                    return Shell.run(launchctl, ["bootstrap", Launchctl.domain, paths.launchAgentPlist.path]).status == 0
                }
                return Shell.run(launchctl, ["kickstart", Launchctl.target]).status == 0
            },
            stop: {
                guard pid() != nil else { return true }
                _ = Shell.run(launchctl, ["kill", "SIGTERM", Launchctl.target])
                let deadline = Date().addingTimeInterval(10)
                while pid() != nil && Date() < deadline { Thread.sleep(forTimeInterval: 0.1) }
                return pid() == nil
            })
    }
```

```swift
import DrypCore
import Foundation

/// Write a request, wait for the agent to acknowledge it, and report the real result.
enum Requests {
    static func start(_ mode: Mode, seconds: TimeInterval?, env: CLIEnvironment) -> Int32 {
        let now = env.now().wholeSeconds
        let session = Session(started: now, until: seconds.map { now.addingTimeInterval($0) })
        let store = StateStore(paths: env.paths)
        let written: DrypState
        do {
            written = try store.update { $0[mode] = session }
        } catch {
            env.err("dryp: \(error)")
            return 1
        }
        guard let applied = awaitAck(rev: written.rev, env: env) else { return notResponding(env) }
        if let r = applied.rejected, r.mode == mode, r.rev >= written.rev {
            env.err("dryp: \(r.reason)")
            return 1
        }
        guard store.current()[mode] == session else {
            env.err("dryp: the \(mode.rawValue) request was replaced by another one before it took effect")
            return 1
        }
        if mode == .nosleep && env.readSleepDisabled() != true {
            env.err("dryp: nosleep was accepted but SleepDisabled isn't 1 — see `dryp status`")
            return 1
        }
        env.out(Format.started(mode, session))
        return 0
    }

    static func stop(_ modes: [Mode], env: CLIEnvironment) -> Int32 {
        let store = StateStore(paths: env.paths)
        let touchesSleep = modes.contains(.nosleep)
        let written: DrypState
        do {
            written = try store.update { s in
                for m in modes { s[m] = nil }
                if touchesSleep { s.restoreSleep = true }
            }
        } catch {
            env.err("dryp: \(error)")
            return 1
        }
        guard awaitAck(rev: written.rev, env: env) != nil else { return notResponding(env) }
        if touchesSleep && env.readSleepDisabled() == true {
            env.err("dryp: sleep is still disabled; run: \(PmsetCommand.manualRestore)")
            return 1
        }
        switch (modes.count, touchesSleep) {
        case (2, _): env.out("off; sleep is enabled")
        case (_, true): env.out("nosleep off; sleep is enabled")
        default: env.out("\(modes[0].rawValue) off")
        }
        return 0
    }

    /// Waits for applied.rev to reach `rev`. Starts the agent if it isn't running, and retries once.
    static func awaitAck(rev: Int, env: CLIEnvironment) -> Applied? {
        let applied = AppliedStore(paths: env.paths)
        func poll() -> Applied? {
            let deadline = Date().addingTimeInterval(env.waitTimeout)
            repeat {
                let a = applied.read()
                if a.rev >= rev { return a }
                Thread.sleep(forTimeInterval: env.pollInterval)
            } while Date() < deadline
            return nil
        }
        if env.agent.pid() == nil {
            _ = env.agent.start()
        } else {
            env.agent.nudge()
        }
        if let a = poll() { return a }
        _ = env.agent.start()
        return poll()
    }

    private static func notResponding(_ env: CLIEnvironment) -> Int32 {
        env.err("dryp: the dryp agent isn't responding (see \(env.paths.logFile.path))")
        return 1
    }
}
```

```swift
/// Parses and runs; maps ArgumentParser's usage exit (64) to the spec's 2.
public enum DrypMain {
    public static func run(_ arguments: [String]) -> Int32 {
        do {
            var command = try Dryp.parseAsRoot(arguments)
            try command.run()
            return 0
        } catch {
            let code = Dryp.exitCode(for: error)
            let message = Dryp.fullMessage(for: error)
            if code == .success {
                if !message.isEmpty { CLIEnvironment.current.out(message) }
                return 0
            }
            if !message.isEmpty { CLIEnvironment.current.err(message) }
            return code == .validationFailure ? 2 : code.rawValue
        }
    }

enum ModeCommand {
    static func validate(_ value: String?, hours: Bool) throws {
        guard let value else { return }
        if value == "off" {
            if hours { throw ValidationError("'off' doesn't take -h") }
            return
        }
        do { _ = try DurationParser.parse(value, hours: hours) } catch { throw ValidationError("\(error)") }
    }

    static func run(_ mode: Mode, value: String?, hours: Bool) throws {
        let env = CLIEnvironment.current
        let code: Int32
        if value == "off" {
            code = Requests.stop([mode], env: env)
        } else {
            code = Requests.start(mode, seconds: try value.map { try DurationParser.parse($0, hours: hours) }, env: env)
        }
        if code != 0 { throw ExitCode(code) }
    }
```

```swift
struct Status: ParsableCommand {
    static let configuration = CommandConfiguration(
        abstract: "Show both modes, the real SleepDisabled value, and the agent. Never starts the agent.")

    func run() throws {
        let env = CLIEnvironment.current
        Status.lines(env: env, timeZone: .current).forEach(env.out)
    }

    static func lines(env: CLIEnvironment, timeZone: TimeZone) -> [String] {
        let state = StateStore(paths: env.paths).current()
        let applied = AppliedStore(paths: env.paths).read()
        let now = env.now()
        let live = env.readSleepDisabled()
        let pid = env.agent.pid()

        var lines = ["caf:      " + Format.status(state.caf, now: now, timeZone: timeZone)]
        if state.nosleep == nil && !env.nosleepInstalled() {
            lines.append("nosleep:  not set up — run ./install.sh --nosleep")
        } else {
            lines.append("nosleep:  " + Format.status(state.nosleep, now: now, timeZone: timeZone))
        }
        lines.append("pmset:    " + (live.map { "SleepDisabled \($0 ? 1 : 0)" } ?? "unknown"))
        lines.append("agent:    " + (pid.map { "running (pid \($0))" } ?? "not running"))

        if applied.restoreFailed && live == true {
            lines.append("warning:  dryp couldn't restore sleep — run: \(PmsetCommand.manualRestore)")
        } else if live == true && state.nosleep == nil {
            lines.append("warning:  sleep is disabled but dryp's nosleep is off — run `dryp nosleep off` or use Restore Sleep in the menu")
        } else if live == false && state.nosleep != nil && pid != nil {
            lines.append("warning:  nosleep is on but SleepDisabled is 0 — see \(env.paths.logFile.path)")
        }
        return lines
    }
```

```swift
struct AppCommand: ParsableCommand {
    static let configuration = CommandConfiguration(
        commandName: "app",
        abstract: "Start or stop the menu-bar agent, or set Open at Login.",
        subcommands: [Start.self, Stop.self, Login.self])

    struct Start: ParsableCommand {
        static let configuration = CommandConfiguration(abstract: "Launch the agent and keep it in the menu bar.")

        func run() throws {
            let env = CLIEnvironment.current
            StartMarker.touch(env.paths)
            _ = env.agent.start()
            let deadline = Date().addingTimeInterval(env.waitTimeout)
            while env.agent.pid() == nil && Date() < deadline { Thread.sleep(forTimeInterval: env.pollInterval) }
            guard let pid = env.agent.pid() else {
                env.err("dryp: the agent didn't start (see \(env.paths.logFile.path))")
                throw ExitCode(1)
            }
            env.out("dryp is running (pid \(pid))")
        }
    }

    struct Stop: ParsableCommand {
        static let configuration = CommandConfiguration(
            abstract: "Quit the agent: stops both modes and restores sleep first.")

        func run() throws {
            let env = CLIEnvironment.current
            guard env.agent.stop() else {
                env.err("dryp: the agent didn't exit within 10 seconds")
                throw ExitCode(1)
            }
            if AppliedStore(paths: env.paths).read().nosleepSet && env.readSleepDisabled() == true {
                env.err("dryp: stopped, but sleep is still disabled; run: \(PmsetCommand.manualRestore)")
                throw ExitCode(1)
            }
            env.out("dryp stopped; sleep is enabled")
        }
    }
```

```swift
import AppKit

/// dryp's app icon (Finder, Spotlight, System Settings, the About panel): the white filled cup on a warm
/// coffee-brown tile, on the macOS icon grid — an 824/1024 rounded square, centred, with room for its shadow.
/// Drawn in code (like peel) so no binary icon is checked in.
public enum DrypIcon {
    public static func appIconPNG(pixels px: Int) -> Data {
        let rep = NSBitmapImageRep(bitmapDataPlanes: nil, pixelsWide: px, pixelsHigh: px, bitsPerSample: 8,
                                   samplesPerPixel: 4, hasAlpha: true, isPlanar: false,
                                   colorSpaceName: .deviceRGB, bytesPerRow: 0, bitsPerPixel: 0)!
        NSGraphicsContext.saveGraphicsState()
        NSGraphicsContext.current = NSGraphicsContext(bitmapImageRep: rep)
        let s = CGFloat(px) / 1024
        let tile = NSRect(x: 100 * s, y: 100 * s, width: 824 * s, height: 824 * s)
        let shape = NSBezierPath(roundedRect: tile, xRadius: 185 * s, yRadius: 185 * s)

        NSGraphicsContext.saveGraphicsState()
        let shadow = NSShadow()
        shadow.shadowColor = NSColor.black.withAlphaComponent(0.3)
        shadow.shadowOffset = NSSize(width: 0, height: -10 * s)
        shadow.shadowBlurRadius = 24 * s
        shadow.set()
        NSColor.black.setFill()
        shape.fill()
        NSGraphicsContext.restoreGraphicsState()

        // Coffee brown, lighter (crema) at the top.
        NSGradient(starting: NSColor(srgbRed: 0.71, green: 0.47, blue: 0.29, alpha: 1),
                   ending: NSColor(srgbRed: 0.36, green: 0.21, blue: 0.12, alpha: 1))!
            .draw(in: shape, angle: -90)

        drawCup(in: tile.insetBy(dx: tile.width * 0.18, dy: tile.height * 0.18))

        NSGraphicsContext.restoreGraphicsState()
        return rep.representation(using: .png, properties: [:])!
    }

    /// The same SF Symbol the menu bar uses, rendered white and centred.
    static func drawCup(in rect: NSRect) {
        let config = NSImage.SymbolConfiguration(pointSize: rect.height * 0.8, weight: .medium)
            .applying(NSImage.SymbolConfiguration(paletteColors: [.white]))
        guard let symbol = NSImage(systemSymbolName: "cup.and.saucer.fill", accessibilityDescription: nil)?
            .withSymbolConfiguration(config) else { return }
        let size = symbol.size
        let scale = min(rect.width / size.width, rect.height / size.height)
        let drawn = NSSize(width: size.width * scale, height: size.height * scale)
        let origin = NSPoint(x: rect.midX - drawn.width / 2, y: rect.midY - drawn.height / 2)
        symbol.draw(in: NSRect(origin: origin, size: drawn))
    }

    /// Writes the .iconset folder `iconutil -c icns` turns into the app's icon: each size at 1x and 2x.
    public static func writeIconset(to directory: URL) throws {
        try FileManager.default.createDirectory(at: directory, withIntermediateDirectories: true)
        for size in [16, 32, 128, 256, 512] {
            try appIconPNG(pixels: size).write(to: directory.appendingPathComponent("icon_\(size)x\(size).png"))
            try appIconPNG(pixels: size * 2).write(to: directory.appendingPathComponent("icon_\(size)x\(size)@2x.png"))
        }
    }
}
```

```swift
final class IOPMCafAssertions: PowerAssertions {
    // -d, -i, -m, -s (the last only takes effect on AC power).
    private static let types = ["PreventUserIdleDisplaySleep", "PreventUserIdleSystemSleep",
                                "PreventDiskIdle", "PreventSystemSleep"]

        var taken: [IOPMAssertionID] = []
        for type in Self.types {
            var id = IOPMAssertionID(0)

    private var source: CFRunLoopSource?

        source = IOPSNotificationCreateRunLoopSource({ context in
```

```swift
            content.title = NoticeText.restoreFailedTitle
            content.body = NoticeText.restoreFailedBody
        }

        }
```

```swift
final class DirectoryWatcher {
    private let dir: URL
    private let onChange: () -> Void
    private let log: (String) -> Void
    private var source: DispatchSourceFileSystemObject?
    private var pending = false

    init(dir: URL, log: @escaping (String) -> Void, onChange: @escaping () -> Void) {
        self.dir = dir
        self.log = log
        self.onChange = onChange
        arm()
    }

    private func arm() {
        try? FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        let fd = open(dir.path, O_EVTONLY)
        guard fd >= 0 else {
            log("watcher: cannot open \(dir.path)")
            return
        }
        let src = DispatchSource.makeFileSystemObjectSource(fileDescriptor: fd, eventMask: [.write, .delete, .rename], queue: .main)
        src.setEventHandler { [weak self] in
            guard let self else { return }
            // The directory itself was removed or moved (e.g. by uninstall): re-arm on a fresh one.
            if !src.data.intersection([.delete, .rename]).isEmpty {
                src.cancel()
                self.arm()
            }
            self.fire()
        }
        src.setCancelHandler { close(fd) }
        src.resume()
        source = src
    }

    /// One atomic write produces several events; collapse them into one call.
    private func fire() {
        guard !pending else { return }
        pending = true
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.1) { [weak self] in
            self?.pending = false
            self?.onChange()
        }
    }
}
```

```swift
import AppKit
import DrypCore

final class AppDelegate: NSObject, NSApplicationDelegate {
    let paths: Paths
    let log: FileLog
    private(set) var reconciler: Reconciler!
    private var menu: StatusMenu?
    private var watcher: DirectoryWatcher?
    private var power: IOPowerSource!
    private var notifier: UserNotifier!
    private var timer: Timer?
    private var sigterm: DispatchSourceSignal?
    private var shuttingDown = false

    init(paths: Paths, log: FileLog) {
        self.paths = paths
        self.log = log
    }

    func applicationDidFinishLaunching(_ notification: Notification) {
        let startRequested = StartMarker.consume(paths)
        power = IOPowerSource()
        notifier = UserNotifier(log: log.write)
        reconciler = Reconciler(
            store: StateStore(paths: paths), appliedStore: AppliedStore(paths: paths),
            caf: IOPMCafAssertions(), sleep: SudoPmset(log: log.write), power: power, notifier: notifier,
            now: Date.init, bootTime: BootTime.current(), log: log.write)
        log.write("agent started (dryp \(DrypVersion.current))")

        let next = reconciler.reconcile()
        if LoginCheck.shouldExit(state: reconciler.state, applied: reconciler.applied,
                                 foreign: reconciler.foreign, startRequested: startRequested) {
            log.write("login check: nothing to watch and Open at Login is off; exiting")
            exit(0)
        }

        notifier.onExtend = { [weak self] mode in
            self?.reconciler.extend(mode, by: 3600)
            self?.reconcile()
        }
        notifier.requestAuthorization()
        menu = StatusMenu(app: self)
        watcher = DirectoryWatcher(dir: paths.configDir, log: log.write) { [weak self] in self?.reconcile() }
        power.onChange = { [weak self] in self?.reconcile() }
        NSWorkspace.shared.notificationCenter.addObserver(
            forName: NSWorkspace.didWakeNotification, object: nil, queue: .main) { [weak self] _ in self?.reconcile() }
        NotificationCenter.default.addObserver(
            forName: .NSSystemClockDidChange, object: nil, queue: .main) { [weak self] _ in self?.reconcile() }
        installSigterm()
        arm(next)
        menu?.refresh()
    }

    // MARK: - Reconcile loop

    func reconcile() {
        guard !shuttingDown, let reconciler else { return }
        arm(reconciler.reconcile())
        menu?.refresh()
    }

    /// One timer, for the next warning, deadline or restore retry. A quarter second late so `until <= now`.
    private func arm(_ date: Date?) {
        timer?.invalidate()
        timer = nil
        guard let date else { return }
        let t = Timer(fire: max(date, Date()).addingTimeInterval(0.25), interval: 0, repeats: false) { [weak self] _ in
            self?.reconcile()
        }
        RunLoop.main.add(t, forMode: .common)
        timer = t
    }

    // MARK: - Actions (the menu calls these; each writes state.json exactly like the CLI)

    func request(_ mode: Mode, seconds: TimeInterval?) {
        let now = Date().wholeSeconds
        let written: DrypState
        do {
            written = try StateStore(paths: paths).update {
                $0[mode] = Session(started: now, until: seconds.map { now.addingTimeInterval($0) })
            }
        } catch {
            Alerts.info("Couldn't start \(mode.title)", "\(error)")
            return
        }
        reconcile()
        if let r = reconciler.applied.rejected, r.mode == mode, r.rev >= written.rev {
            Alerts.info("Couldn't start \(mode.title)", r.reason)
        }
    }

    func stop(_ modes: [Mode]) {
        _ = try? StateStore(paths: paths).update { s in
            for m in modes { s[m] = nil }
            if modes.contains(.nosleep) { s.restoreSleep = true }
        }
        reconcile()
    }

    /// Menu "Restore Sleep" and "Retry".
    func restoreSleep() {
        _ = try? StateStore(paths: paths).update { $0.restoreSleep = true }
        reconcile()
    }

    func setPref(_ body: (inout Prefs) -> Void) {
        _ = try? StateStore(paths: paths).update { body(&$0.prefs) }
        reconcile()
    }

    func quitFromMenu() {
        if reconciler.state.anyActive && !Alerts.confirmQuit() { return }
        shutdownAndExit(interactive: true)
    }

    // MARK: - Shutdown

    private func installSigterm() {
        signal(SIGTERM, SIG_IGN)
        let src = DispatchSource.makeSignalSource(signal: SIGTERM, queue: .main)
        src.setEventHandler { [weak self] in self?.shutdownAndExit(interactive: false) }
        src.resume()
        sigterm = src
    }

    func applicationShouldTerminate(_ sender: NSApplication) -> NSApplication.TerminateReply {
        // Logout and restart arrive here.
        if !shuttingDown { shutdownAndExit(interactive: false) }
        return .terminateNow
    }

    /// Clears both modes, releases caf, restores sleep, and exits only once SleepDisabled reads 0 — or, when
    /// interactive, when the user picks Quit Anyway. Exit status 0 so launchd doesn't respawn a deliberate quit.
    private func shutdownAndExit(interactive: Bool) {
        shuttingDown = true
        timer?.invalidate()
        while !reconciler.shutdown() {
            guard interactive else {
                log.write("shutdown: sleep could not be restored; flagged for the next login check")
                break
            }
            if Alerts.restoreFailed() == .quitAnyway {
                log.write("shutdown: user chose Quit Anyway with sleep still disabled")
                break
            }
        }
        log.write("agent exiting")
        exit(0)
    }
}
```

```swift
import AppKit
import DrypCore

/// Draws the fixed slots: cup (caf) then laptop (nosleep). Idle = dimmed, active = full strength, no limit
/// = small orange dot, alert = orange laptop. Drawn at display time so labelColor follows the menu bar's
/// light/dark appearance.
enum IconRenderer {
    private static let symbols: [Mode: (idle: String, active: String)] = [
        .caf: ("cup.and.saucer", "cup.and.saucer.fill"),
        .nosleep: ("laptopcomputer", "laptopcomputer"),
    ]
    private static let glyphPoints: CGFloat = 14
    private static let height: CGFloat = 18
    private static let gap: CGFloat = 5
    private static let font = NSFont.monospacedDigitSystemFont(ofSize: 12, weight: .regular)

    static func image(for slots: [Slot]) -> NSImage {
        let glyphs = slots.map { slot -> NSImage in
            let name = slot.active ? symbols[slot.mode]!.active : symbols[slot.mode]!.idle
            let config = NSImage.SymbolConfiguration(pointSize: glyphPoints, weight: .regular)
            return NSImage(systemSymbolName: name, accessibilityDescription: nil)!.withSymbolConfiguration(config)!
        }
        let texts = slots.map { $0.timeText.map { NSAttributedString(string: $0, attributes: [.font: font]) } }
        var width: CGFloat = 0
        for (i, glyph) in glyphs.enumerated() {
            if i > 0 { width += gap }
            width += glyph.size.width
            if let t = texts[i] { width += 2 + ceil(t.size().width) }
        }

        let image = NSImage(size: NSSize(width: max(width, 1), height: height), flipped: false) { _ in
            var x: CGFloat = 0
            for (i, slot) in slots.enumerated() {
                if i > 0 { x += gap }
                let glyph = glyphs[i]
                var color = NSColor.labelColor.withAlphaComponent(slot.active ? 1 : 0.45)
                if slot.alert { color = .systemOrange }
                let rect = NSRect(x: x, y: (height - glyph.size.height) / 2, width: glyph.size.width, height: glyph.size.height)
                tinted(glyph, color).draw(in: rect)
                if slot.unlimited || slot.alert {
                    NSColor.systemOrange.setFill()
                    NSBezierPath(ovalIn: NSRect(x: rect.maxX - 4, y: rect.maxY - 4, width: 5, height: 5)).fill()
                }
                x = rect.maxX
                if let text = slot.timeText {
                    let s = NSAttributedString(string: text, attributes: [.font: font, .foregroundColor: NSColor.labelColor])
                    let size = s.size()
                    s.draw(at: NSPoint(x: x + 2, y: (height - size.height) / 2))
                    x += 2 + ceil(size.width)
                }
            }
            return true
        }
        image.isTemplate = false
        return image
    }

    private static func tinted(_ image: NSImage, _ color: NSColor) -> NSImage {
        NSImage(size: image.size, flipped: false) { rect in
            image.draw(in: rect)
            color.set()
            rect.fill(using: .sourceAtop)
            return true
        }
    }
}
```

```swift
import AppKit
import DrypCore

/// The menu-bar item. A plain NSMenu, like mutewake: system styling, keyboard navigation and accessibility
/// for free. Every action goes through AppDelegate, which writes state.json exactly like the CLI.
final class StatusMenu: NSObject, NSMenuDelegate {
    private unowned let app: AppDelegate
    private let item = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
    private let menu = NSMenu()
    private var liveTimer: Timer?
    private let presets: [(String, TimeInterval)] = [
        ("30 min", 1800), ("45 min", 2700), ("1 hr", 3600), ("2 hr", 7200), ("4 hr", 14_400), ("8 hr", 28_800),
    ]

    init(app: AppDelegate) {
        self.app = app
        super.init()
        menu.delegate = self
        menu.autoenablesItems = false
        item.menu = menu
        refresh()
    }

    private var slots: [Slot] {
        let r = app.reconciler!
        return MenuBarModel.slots(state: r.state, now: Date(), foreign: r.foreign,
                                  restoreFailed: r.applied.restoreFailed, nosleepAvailable: r.nosleepAvailable)
    }

    func refresh() {
        let current = slots
        item.button?.image = IconRenderer.image(for: current)
        item.button?.imagePosition = .imageOnly
        item.button?.setAccessibilityLabel(MenuBarModel.accessibilityLabel(current))
        // An open menu is not rebuilt (that would collapse open submenus); its status rows tick via liveTimer.
    }

    // MARK: - NSMenuDelegate

    func menuNeedsUpdate(_ menu: NSMenu) {
        app.reconciler.refreshAvailability()
        rebuild()
    }

    func menuWillOpen(_ menu: NSMenu) {
        let t = Timer(timeInterval: 5, repeats: true) { [weak self] _ in self?.refreshStatusRows() }
        RunLoop.main.add(t, forMode: .eventTracking)
        liveTimer = t
    }

    func menuDidClose(_ menu: NSMenu) {
        liveTimer?.invalidate()
        liveTimer = nil
    }

    // MARK: - Building

    private func rebuild() {
        let r = app.reconciler!
        menu.removeAllItems()
        menu.addItem(statusRow(.caf))
        if r.nosleepAvailable || r.state.nosleep != nil {
            menu.addItem(statusRow(.nosleep))
        } else {
            menu.addItem(plain("Nosleep: not set up"))
        }
        if r.foreign {
            menu.addItem(plain("Sleep disabled outside dryp", dot: true))
            menu.addItem(action("Restore Sleep") { [weak self] in self?.app.restoreSleep() })
        }
        if r.applied.restoreFailed {
            menu.addItem(plain("Couldn't restore sleep — \(PmsetCommand.manualRestore)", dot: true))
            menu.addItem(action("Retry") { [weak self] in self?.app.restoreSleep() })
        }
        menu.addItem(.separator())
        menu.addItem(modeSubmenu(.caf))
        if r.nosleepAvailable || r.state.nosleep != nil {
            menu.addItem(modeSubmenu(.nosleep))
        } else {
            menu.addItem(action("Set Up Nosleep…") { Alerts.setUpNosleep() })
        }
        menu.addItem(.separator())
        let stopAll = action("Stop All", key: ".") { [weak self] in self?.app.stop([.caf, .nosleep]) }
        stopAll.isEnabled = r.state.anyActive
        menu.addItem(stopAll)
        menu.addItem(.separator())
        menu.addItem(showTimeSubmenu())
        let login = action("Open at Login") { [weak self] in
            self?.app.setPref { $0.openAtLogin.toggle() }
        }
        login.state = r.state.prefs.openAtLogin ? .on : .off
        menu.addItem(login)
        menu.addItem(action("About dryp") {
            NSApp.activate(ignoringOtherApps: true)
            NSApp.orderFrontStandardAboutPanel(nil)
        })
        menu.addItem(action("Quit", key: "q") { [weak self] in self?.app.quitFromMenu() })
    }

    private func refreshStatusRows() {
        guard menu.numberOfItems >= 2 else { return }
        let r = app.reconciler!
        menu.item(at: 0)?.attributedTitle = statusTitle(.caf)
        if r.nosleepAvailable || r.state.nosleep != nil { menu.item(at: 1)?.attributedTitle = statusTitle(.nosleep) }
        refresh()
    }

    private func statusTitle(_ mode: Mode) -> NSAttributedString {
        let session = app.reconciler.state[mode]
        let title = NSMutableAttributedString(string: "\(mode.title): \(Format.status(session, now: Date()))")
        if session?.isUnlimited == true {
            title.append(NSAttributedString(string: "  ●", attributes: [.foregroundColor: NSColor.systemOrange]))
        }
        return title
    }

    private func statusRow(_ mode: Mode) -> NSMenuItem {
        let item = NSMenuItem(title: "", action: nil, keyEquivalent: "")
        item.attributedTitle = statusTitle(mode)
        item.isEnabled = true   // enabled with no action: drawn normally, not greyed
        return item
    }

    private func plain(_ text: String, dot: Bool = false) -> NSMenuItem {
        let item = NSMenuItem(title: text, action: nil, keyEquivalent: "")
        if dot {
            let title = NSMutableAttributedString(string: text)
            title.append(NSAttributedString(string: "  ●", attributes: [.foregroundColor: NSColor.systemOrange]))
            item.attributedTitle = title
        }
        return item
    }

    private func modeSubmenu(_ mode: Mode) -> NSMenuItem {
        let parent = NSMenuItem(title: mode == .caf ? "Caffeinate" : "Nosleep (lid closed)", action: nil, keyEquivalent: "")
        let sub = NSMenu()
        sub.autoenablesItems = false
        for (title, seconds) in presets {
            sub.addItem(action(title) { [weak self] in self?.app.request(mode, seconds: seconds) })
        }
        sub.addItem(action("No Limit") { [weak self] in self?.app.request(mode, seconds: nil) })
        sub.addItem(action("Custom…") { [weak self] in
            if let seconds = Alerts.customDuration(for: mode) { self?.app.request(mode, seconds: seconds) }
        })
        sub.addItem(.separator())
        let stop = action("Stop") { [weak self] in self?.app.stop([mode]) }
        stop.isEnabled = app.reconciler.state[mode] != nil
        sub.addItem(stop)
        parent.submenu = sub
        return parent
    }

    private func showTimeSubmenu() -> NSMenuItem {
        let parent = NSMenuItem(title: "Show Time in Menu Bar", action: nil, keyEquivalent: "")
        let sub = NSMenu()
        sub.autoenablesItems = false
        for mode in Mode.allCases {
            let item = action(mode.title) { [weak self] in
                self?.app.setPref { $0.setShowsTime(mode, !$0.showsTime(mode)) }
            }
            item.state = app.reconciler.state.prefs.showsTime(mode) ? .on : .off
            sub.addItem(item)
        }
        parent.submenu = sub
        return parent
    }

    // MARK: - Closure-backed items

    private final class Handler: NSObject {
        let run: () -> Void
        init(_ run: @escaping () -> Void) { self.run = run }
        @objc func fire() { run() }
    }

    private func action(_ title: String, key: String = "", _ run: @escaping () -> Void) -> NSMenuItem {
        let handler = Handler(run)
        let item = NSMenuItem(title: title, action: #selector(Handler.fire), keyEquivalent: key)
        item.target = handler
        item.representedObject = handler   // keeps the handler alive as long as the item
        item.isEnabled = true
        return item
    }
}
```

```swift
import ArgumentParser
import DrypCore
import Foundation

enum Lifecycle {
    enum ArchiveKind: Equatable { case tarball, zip }

    static func installArguments(_ m: Manifest) -> [String] {
        ["\(m.source)/install.sh", m.nosleep ? "--nosleep" : "--no-nosleep"]
    }

    static func archiveKind(_ path: String) -> ArchiveKind? {
        let lower = path.lowercased()
        if lower.hasSuffix(".tar.gz") || lower.hasSuffix(".tgz") { return .tarball }
        if lower.hasSuffix(".zip") { return .zip }
        return nil
    }

    /// Unpacks an archive into a temp folder and returns the folder containing install.sh.
    static func unpack(_ archive: String, kind: ArchiveKind, env: CLIEnvironment) -> URL? {
        let dest = FileManager.default.temporaryDirectory.appendingPathComponent("dryp-update-\(UUID().uuidString)")
        try? FileManager.default.createDirectory(at: dest, withIntermediateDirectories: true)
        let status = kind == .tarball
            ? env.run("/usr/bin/tar", ["-xzf", archive, "-C", dest.path], [:])
            : env.run("/usr/bin/ditto", ["-x", "-k", archive, dest.path], [:])
        guard status == 0 else { return nil }
        if FileManager.default.fileExists(atPath: dest.appendingPathComponent("install.sh").path) { return dest }
        let children = (try? FileManager.default.contentsOfDirectory(at: dest, includingPropertiesForKeys: nil)) ?? []
        return children.first { FileManager.default.fileExists(atPath: $0.appendingPathComponent("install.sh").path) }
    }
}

struct Update: ParsableCommand {
    static let configuration = CommandConfiguration(
        abstract: "Pull the latest source, rebuild and reinstall (or install from a directory or archive).")

    @Argument(help: "A source directory or a .tar.gz/.tgz/.zip archive. Default: the recorded source.") var path: String?

    func run() throws {
        let env = CLIEnvironment.current
        guard let manifest = Manifest.read(env.paths) else {
            env.err("dryp: no install record at \(env.paths.manifestFile.path); reinstall with ./install.sh")
            throw ExitCode(1)
        }
        var source = manifest
        var environment = ["APP_DIR": manifest.appDir]

        if let path {
            let root: URL
            if let kind = Lifecycle.archiveKind(path) {
                guard let unpacked = Lifecycle.unpack(path, kind: kind, env: env) else {
                    env.err("dryp: couldn't unpack \(path), or it has no install.sh")
                    throw ExitCode(1)
                }
                root = unpacked
            } else {
                root = URL(fileURLWithPath: path)
            }
            source.source = root.path
            // The given folder (or temp unpack) isn't where future updates should come from.
            environment["DRYP_SOURCE"] = manifest.source
        } else if FileManager.default.fileExists(atPath: "\(manifest.source)/.git") {
            env.out("==> Pulling \(manifest.source)")
            guard env.run("/usr/bin/git", ["-C", manifest.source, "pull", "--ff-only"], [:]) == 0 else {
                env.err("dryp: git pull failed; nothing was reinstalled")
                throw ExitCode(1)
            }
        }

        let status = env.run("/bin/bash", Lifecycle.installArguments(source), environment)
        if status != 0 { throw ExitCode(status) }
    }
}

struct Uninstall: ParsableCommand {
    static let configuration = CommandConfiguration(
        abstract: "Stop dryp, restore sleep, and remove the agent, app, CLI, state, logs and sudoers rule.")

    @Flag(help: "Remove everything even if sleep couldn't be restored.") var force = false

    func run() throws {
        let env = CLIEnvironment.current
        let fm = FileManager.default

        _ = env.agent.stop()
        if AppliedStore(paths: env.paths).read().nosleepSet && env.readSleepDisabled() == true && !force {
            env.err("dryp: couldn't restore sleep, so nothing was removed. Fix it with `\(PmsetCommand.manualRestore)` "
                    + "and run `dryp uninstall` again, or pass --force.")
            throw ExitCode(1)
        }

        _ = env.run("/bin/launchctl", ["bootout", Launchctl.target], [:])
        let appDir = Manifest.read(env.paths)?.appDir ?? env.paths.home.appendingPathComponent("Applications").path
        let targets = [
            env.paths.launchAgentPlist,
            URL(fileURLWithPath: appDir).appendingPathComponent("Dryp.app"),
            env.paths.configDir,
            env.paths.dataDir,
            env.paths.logFile,
            env.paths.home.appendingPathComponent("Library/Logs/dryp.err.log"),
            env.paths.cliPath,
        ]
        for url in targets where fm.fileExists(atPath: url.path) {
            do {
                try fm.removeItem(at: url)
                env.out("removed \(url.path)")
            } catch {
                env.err("dryp: couldn't remove \(url.path): \(error.localizedDescription)")
            }
        }

        if env.nosleepInstalled() {
            env.out("==> Removing \(Paths.sudoersFile.path) (sudo will ask for your password)")
            if env.run("/usr/bin/sudo", ["/bin/rm", "-f", Paths.sudoersFile.path], [:]) != 0 {
                env.err("dryp: couldn't remove \(Paths.sudoersFile.path); remove it with: sudo rm \(Paths.sudoersFile.path)")
                throw ExitCode(1)
            }
        }
        env.out("dryp is uninstalled. Remove the dryp aliases from ~/.zshrc if you added them.")
    }
}
```

````markdown
Keeps your Mac awake from the menu bar or the terminal, in two independent ways:

- **caf** — screen and everything stay on (what `caffeinate -dimsu` does).
- **nosleep** — sleep is disabled, so you can close the lid and your agents keep running
  (what `pmset -a disablesleep 1` does). It always cleans up after itself.

## Install

Requires macOS 13+ and the Xcode Command Line Tools (`xcode-select --install`).

```sh
git clone https://github.com/00mkp/dryp.git
cd dryp
./install.sh            # asks whether to enable nosleep
```

`--nosleep` / `--no-nosleep` skip the question. nosleep needs root, so it adds one file,
`/etc/sudoers.d/dryp`, allowing exactly `pmset -a disablesleep 0` and `1` without a password —
nothing else. Without it, dryp runs caf-only.

The installer builds from source (no Gatekeeper prompts, and you can read what you run), puts
`Dryp.app` in `~/Applications` (override with `APP_DIR=…`) and the `dryp` command in `~/.local/bin`.

## Usage

```
dryp caf [N] [-h]        keep awake N minutes (hours with -h); no N = no limit
dryp caf off
dryp nosleep [N] [-h]    disable sleep (lid can close) N minutes / hours; no N = no limit
dryp nosleep off         also restores sleep that something else disabled
dryp off                 stop both
dryp status
dryp app start | stop    stop = end both modes, restore sleep, quit
dryp app login on | off  Open at Login
dryp update [PATH]
dryp uninstall
```

```
$ dryp caf 2 -h
caf on for 2h (until 18:40)
$ dryp status
caf:      on · 1h59m left (until 18:40)
nosleep:  off
pmset:    SleepDisabled 0
agent:    running (pid 4411)
```

## Menu bar

Two fixed glyphs: a cup (caf) and a laptop (nosleep) — dimmed when off, full when on, with an
orange dot when a mode has no time limit. The menu has presets (30 min to 8 hr), No Limit,
Custom…, Stop, Stop All, per-mode "Show Time in Menu Bar", and Open at Login.

You'll get a banner 5 minutes before a timed session ends (with **Extend 1 hr**), and when it
ends. nosleep stops by itself on battery at 10 %.

## Safety

nosleep changes a system setting that survives closing the terminal and rebooting, so dryp:

- restores sleep on every way it stops — Quit, `dryp app stop`, logout, shutdown, uninstall —
  and only exits once `SleepDisabled` reads 0;
- is restarted by launchd if it crashes, and checks at every login, so a power cut mid-session
  is cleaned up at the next boot;
- never undoes a `disablesleep` it didn't set without being asked, but flags it in the menu
  with a one-click **Restore Sleep**.

## How it works

The menu-bar agent is the only thing that touches power settings. The CLI and the menu write
requests to `~/.config/dryp/state.json`; the agent notices (a kernel file event — no polling),
acts, and records what it did in `~/.local/share/dryp/applied.json`, which the CLI waits for so it
can report the real result. Log: `~/Library/Logs/dryp.log`.
````
